Made with android Studio. 

Football Drafts aims to get football lovers together into a match as 
simple and quick as possible

• The app utilises the Places API to get a location and store this
• Firestore firebase is used to store essential data such as users, 
lineups, matches ect.

Users are able to:
• Create a lineup including family members and friends
• Search for matches and send requests
• Create their own match
• Receive requests on home page


I chose the MVVM architecture because it helps promote testablility and maintainability. Some sections may also be reused in others to prevent redundancy and helps code readability.
Firebase was used since it provides a variety of services, User friendly and documentation making it easy to learn. It also interacts with Google Cloud to help with integrating APIs simpler.
Technologies:
Firebase Authentication
Cloud Firestore
Google Places API
